# PA1-search
This project follows a Pacman agent that will find paths through its maze world, both to reach a particular location and to collect food efficiently. We built general search algorithms and apply them to Pacman scenarios.

Person A: search.py (Q1–Q4). Write the generic graph search and the four algorithms on top of it. It's worth 60 points, but it's less work than it sounds: once DFS is correct, BFS, UCS, and A* are mostly fringe swaps.

Person B: searchAgents.py (Q5–Q6). Design the CornersProblem state and successor function, then the corners heuristic. It's only 40 points, but it takes more thought, especially getting the heuristic under the 1200-expansion threshold.

For the bonus, A could take Q8 (closest-dot search), since it's a short BFS-based function and helps even out the load. Q7 (food heuristic) is harder and fits whoever finishes first.
